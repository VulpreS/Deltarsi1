# Новые инструкции — контекст для Codex

## Цель
Реализовать и проверить торгового бота для криптовалютного проп-счёта Upscale. **Торговые сигналы — только пользовательский Pine/DeltaRSI**, не альтернативный сигнал Codex. Решение принимать исключительно после закрытия 4-часовой свечи; исполнение, SL/TP и трейлинг отслеживать по 1-часовым свечам (для реальной торговли — по биржевым данным/ордерам). Не использовать незакрытые свечи для сигнала.

## ВАЖНО: точность сигнала
Финальная формула пользователя: RSI(27) с RMA (Wilder) и EMA(7), применённая к RSI; **DeltaRSI = RSI(27) − EMA(RSI(27), 7)**. Гистограмма синяя/красная, три степени интенсивности. Базовый вход: смена интенсивности **средняя → слабая** в пределах текущего цвета (ослабление красной — кандидат в лонг, синей — в шорт). Дополнительные предпочтения пользователя: 2-я/3-я волна затухания, дивергенция с экстремумом цены, подтверждающий фитиль свечи; старший 4h, 1h для синхронизации. Нельзя объявлять все эти субъективные фильтры автоматизированными, пока они не формализованы и не проверены.

**Предупреждение:** прежние бэктесты использовали функцию `experiments/pine_vs_codex/run.py:pine_events` — приближённый Pine-сигнал (исторически RSI12/SMA21/EMA7), НЕ доказанную точную реализацию финального RSI27. Поэтому цифры прежних тестов нельзя приписывать точному финальному сигналу. Перед запуском реальных сделок обеспечить parity с исходным Pine Script и повторить бэктест.

## Зафиксированная базовая конфигурация
- Начальный депозит: **$5 000** в тестовой модели. Позиция: **20% от общего стартового депозита** ($1 000 при $5 000). Для live отдельно уточнить, считать ли 20% от начального или текущего баланса; не увеличивать позицию автоматически без подтверждения.
- Максимум **3 открытые позиции** одновременно (суммарно до 60% исходного депозита).
- Максимальное удержание каждой сделки: **48 часов** от входа. При достижении лимита закрыть позицию по рынку, если ранее не сработали SL/TP/трейлинг. Приоритет стопа при неоднозначности внутри часовой OHLC-свечи.
- Комиссия для моделирования: 0,08% на сторону; спред: 0,02% round-trip; funding ранее исключался.
- Проп-лимиты: **5% дневной, 10% общий**. Проверять по equity, включая плавающий P&L и комиссии; контролировать на каждом обновлении, а не только при закрытии свечи. Точную методику Upscale и сброс в 00:00 UTC проверить по официальным условиям перед live. Останавливать новые входы и защищать позиции до достижения границ.
- Уровни SL/TP и трейлинга задаются **в ATR, а не процентах**. ATR рассчитывается на закрытых 4h свечах. Направление: long — SL ниже входа, TP выше; short — наоборот.

Настройки зафиксированы в `experiments/max_strategy_grid/pine_baseline_2026-10-29.json`. **Единое время удержания 48 часов для всех инструментов**, индивидуальные сроки не применять.

## Правила реализации
1. Не переоптимизировать указанные параметры и не подменять сигнал «Codex».
2. Проверить отсутствие look-ahead: сигнал появляется только на закрытии 4h, вход — на следующей доступной цене, ATR известен на момент сигнала.
3. Не открывать новую сделку по монете, если уже есть открытая; максимум 3 позиции на счёте.
4. Устанавливать SL/TP сразу при открытии; у TON трейлинг активировать при благоприятном ходе на 3 ATR и вести на расстоянии 0.5 ATR от лучшей достигнутой цены, не ослабляя стоп.
5. Закрывать позицию не позднее 48 часов; учитывать проскальзывание и фактическую комиссию.
6. Отдельно аудировать правила дневного и общего drawdown, открытый P&L, переходы между фазами и дневную базу.
7. Сначала paper/demo, журнал сделок, независимая проверка сигналов и риск-ограничений. Никаких реальных ордеров без явного подтверждения.
