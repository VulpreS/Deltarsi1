# КОДЕКСУ: ИСПОЛЬЗОВАТЬ ИМЕННО СИГНАЛ ИЗ УСПЕШНЫХ БЭКТЕСТОВ

**Не подменять тестовый сигнал на RSI(27).** Результаты, по которым выбраны SL/TP/трейлинг и 48 часов, получены с функцией `pine_events(raw, expanded=False)` в `experiments/pine_vs_codex/run.py`. Это **исполняемый эталон сигнала для воспроизведения тестов**, а не альтернативный сигнал Codex.

## Как воспроизвести
1. Импортировать `pine_events` из `experiments.pine_vs_codex.run`; расчёт дельты выполняет `CausalDelta` из `causal_4h_parity_audit.py`, раскраску — `pine_shade`.
2. Математическая основа этого **проверенного в бэктесте варианта**: `SMA(close,21)` → Wilder RSI(12)/RMA → EMA(RSI,7) → симметричная трансформация Delta; порог интенсивности 60. Точное преобразование взять из `CausalDelta`, не заменять обычной разностью RSI−EMA.
3. На закрытых 4h свечах вход **LONG** при переходе `medium_red -> weak_red`, **SHORT** при `medium_blue -> weak_blue`. `expanded=False`: переходы из `midweak_*` не являются входами.
4. Сигнал известен после закрытия 4h; вход на следующем 4h open. ATR стопов/тейков брать из того же расчёта, что в тестовом `pine_events` (в записи сигнала `atr_4h`).
5. Портфель и исполнение: `experiments/max_strategy_grid/prop_portfolio.py`, **единые 48 часов** на все монеты, 20% начального депозита на позицию ($1 000 при $5 000), максимум 3 открытые позиции, комиссии и спред как в коде.
6. SL/TP/trailing строго из `experiments/max_strategy_grid/pine_baseline_2026-10-29.json`. Не добавлять новые фильтры или входы без отдельного теста.

**Важно:** корневой файл `Delta` — исходный Pine Script, но для совпадения с опубликованными результатами определяющим является именно код `pine_events` + `CausalDelta` + `pine_shade`. В предыдущем README указана более поздняя формула пользователя RSI(27), однако **она не использовалась в этих тестах**. Не менять проверенный вариант без новой команды пользователя и повторного бэктеста.
